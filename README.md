# To run python file 
### Run following commands in terminal
```
python -m venv venv
```
```
./venv/Scripts/Activate.ps1
```
### Install required extensions
```
pip install -r requirements.txt
```
### Then run this command in terminal 
```
uvicorn main:app --reload
```
